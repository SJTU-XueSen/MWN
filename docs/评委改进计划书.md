# 镜·界·联 改进计划书 — 针对评委评语

> 评语：**"选题不错，但非常宏大，很难落实体现可靠真实效果，并且数据检索有点喧宾夺主"**

---

## 一、问题诊断（对照评语逐条拆解）

| 评语要点 | 现状对应问题 | 根因 |
|---|---|---|
| 选题宏大 | 产品同时包含：人格镜像、人生模拟、未来对话、人生体验、活动爬虫、组队协作、AI 检索、语音识别……评委无法在一场演示中看到"一个可信的效果" | 功能摊子铺得太大，缺乏一个**可验证、可量化的核心效果**作为演示主轴 |
| 很难落实体现可靠真实效果 | ① 演示时 AI 生成内容多、但"为什么是这个结果"的证据链展示不足；② 置信度机制存在但未在演示中突出；③ 人格版本对比（成长轨迹）没有可视化 | 只有"生成"，缺少"证明"——评委看不到数据如何一步步变成结论 |
| 数据检索喧宾夺主 | 活动大厅/爬虫/竞赛播报/AI 检索占了侧边栏近一半入口与演示时长，与"认识自己"的核心叙事无关 | 外围功能与核心闭环耦合在同一个界面，没有主次 |

---

## 二、核心理念回归：一个可验证的核心效果

**一句话卖点**（评委能记住的）：**"每一个 AI 结论，都能展开成一条真实数据的证据链。"**

对应三大可演示能力：

1. **证据链**：任何人格分数、模拟路径、报告结论旁边都有「为什么」按钮，点击展开 → 引用的具体记忆/事件/记录原文
2. **诚实量化**：置信度 + 数据量可视化（记录数 → 置信度增长曲线），数据不足时系统主动说明
3. **成长可对比**：人格版本 v1 → v2 的差异高亮（哪些维度变了、因为哪条记录/事件变了）

---

## 三、实施计划（三阶段）

### 阶段 A：聚焦核心（第 1 周）— 解决"喧宾夺主"

**A1. 界面主次重构**
- 侧边栏重组：「认识自己」7 个入口置顶为唯一主区；「走向世界」压缩为一个入口（活动大厅收敛为"合作找队友"的辅助页，爬虫/AI 检索/竞赛播报合并为活动大厅内的二级 tab）
- 首页（Dashboard）只保留五段叙事，删除底部零散的统计卡片堆砌
- 演示路径默认隐藏外围功能：演示前可选择「核心模式」（只显示镜像闭环）

**A2. 外围功能降权**
- 爬虫从"每天 2 次全量"降为"手动触发 + 每周 1 次"，标注"实验性数据源"
- AI 检索、竞赛播报保留但移出主导航，作为活动大厅内部功能

### 阶段 B：建立"可靠真实效果"的证据体系（第 2-3 周）— 解决"难以落实"

**B1. 证据链机制（核心）**
- 后端：所有 AI 生成（人格/模拟/报告/对话/推演）在返回结果中附加 `evidence: [...]`，每项含 {来源类型, 来源标题, 引用原文片段, 时间}
- 前端：人格页每个维度、模拟页每条路径、报告页每个结论旁加「为什么」按钮，展开显示证据链
- 实现方式：llm_service 生成后，用规则从 ChromaDB/SQLite 召回引用片段（不依赖 LLM 自述，保证证据真实）

**B2. 置信度可视化**
- Dashboard 人格形成度卡片增加"数据量 → 置信度"曲线（模拟：记录数 x 轴、置信度 y 轴）
- 置信度 <50% 时全局提示条："当前样本较少，这只是你的一个可能侧面"

**B3. 成长对比视图**
- 人格版本历史页新增 v1 vs v2 对比模式：五维差异高亮 + "是什么数据导致了这些变化"（按时间倒序列出新增记录/事件）

### 阶段 C：可演示性工程（第 4 周）— 解决"宏大"

**C1. 标准演示脚本（10 分钟）**
1. 新账号 → 写入 3 条真实记录 + 1 个事件（2 分钟）
2. 展示记忆提炼：记录 → 生命记忆 → 向量入库（1 分钟，可视化流水线）
3. 生成人格 → 打开「为什么」逐条展开证据链（2 分钟）★ 核心
4. 模拟 → 3 条路径，每条路径的 grounding 指向真实记忆（2 分钟）
5. 未来对话：AI 主动引用用户刚写入的经历（1 分钟）
6. 报告 → 结论全部可溯源（1 分钟）
7. 删除账号 → 数据级联清理（1 分钟，收尾展示数据主权）

**C2. 演示数据包**
- 提供一份"演示者专用"真实感数据脚本（非伪造：演示前由演示者本人现场输入），避免用预制假数据
- 预置 2 个差异化演示账号：一个数据丰富（置信度 80%+）、一个空白（诚实低分对比）

### 阶段 D：评委问题预演（第 5 周）

| 评委可能提问 | 回答锚点 |
|---|---|
| "这个 AI 和直接问 ChatGPT 有什么区别？" | 演示证据链：ChatGPT 给结论，我们给"为什么"（引用用户自己的记忆原文） |
| "如何证明效果可靠？" | 诚实机制：置信度随数据量增长的可视化曲线 + 低置信度明确告知 + 结论可追溯 |
| "数据检索和主题有什么关系？" | 已降权为辅助；核心叙事是"认识自己"，活动协作是"认识自己"之后的自然延伸 |

## 三·五、本地 Agent 计划（换电脑后启动，必做项）

> 技术设想（用户已确认）：后端内置 Agent，直接调用本地模型（Qwen3 35B-A3B MoE——
> 35B 参数量保证智能度，3B 激活保证响应速度；128G 统一内存实测 ~140 token/s，优化差时 80-90）。
> 模型分级：「有时间用 pi（强模型），没时间用 hermes（快模型）」。

### E1. 为什么是 Agent（产品层面）
- 现在的产品是**功能集合**（记录/人格/模拟/对话各自为战）；Agent 把它们变成**一个会主动理解你的助手**
- Agent 拥有工具（查记忆、跑分析、做模拟、找活动），能跨功能闭环："你说想创业 → Agent 检索你的记忆 → 生成人格分析 → 给出模拟路径 → 帮你找队友"
- 本地模型解决两个关键问题：**隐私**（人生数据不出本机）+ **成本**（无限调用）

### E2. 架构设计
```
用户输入
  ↓
┌──────────────────────────────┐
│ Agent 循环（tool-calling）     │
│ · 理解意图 → 规划 → 调用工具   │
│ · 工具：search_memory /       │
│   analyze_records /          │
│   generate_persona /         │
│   run_simulation /           │
│   query_activities /         │
│   summarize_records          │
└──────┬───────────────────────┘
       ↓ 模型分级（有时间用 pi / 没时间用 hermes）
┌──────────────────────────────┐
│ 本地 LLM Provider（OpenAI 兼容）│
│ · Qwen3 35B-A3B（复杂任务：    │
│   人格重构/模拟/深度对话）      │
│ · 快模型（日常对话/检索/摘要）  │
│ · Ollama / LM Studio / llama.cpp
└──────┬───────────────────────┘
       ↓ 不可达时自动回退
   DeepSeek → 智谱 → 规则引擎（现有链路不变）
```

### E3. 技术要点
- `llm_service` 增加 LOCAL 提供商：`OPENAI_BASE_URL`（如 `http://localhost:11434/v1`）+ 分级模型配置
- 提供商优先级链：**本地(分级) → DeepSeek → 智谱 → 规则引擎**，本地断连自动降级，零感知
- Agent 工具全部走现有 service 层（vector_store/persona_service/simulation_service…），保证数据铁律不破
- 模型分级路由：任务复杂度 > 阈值（长生成/多步推理）→ 35B；轻量交互 → 快模型；由 Agent 规划器决定

### E4. 里程碑（换电脑后）
| 周 | 交付 |
|---|---|
| 1 | 本地 LLM Provider 接入 + 分级路由 + 自动回退；现有功能全部走本地模型跑通 |
| 2 | Agent 循环框架（意图→规划→工具调用），接入 3 个核心工具（search_memory / generate_persona / run_simulation） |
| 3 | Agent 对话界面（镜像对话页升级）：Agent 主动引用记忆、给出证据链 |
| 4 | 全工具接入 + 分级模型实测调优（延迟/质量平衡表） |

## 四、验证指标（可量化）

- [ ] 人格页每个维度的「为什么」按钮 100% 可展开出 ≥1 条真实证据
- [ ] 模拟路径的 grounding 100% 指向库内真实记忆（自动校验：引用文本必须存在于 ChromaDB/SQLite）
- [ ] 空白账号演示全程不出现任何虚构高分（置信度 ≤ 数据阈值）
- [ ] 10 分钟演示脚本全程跑通、无外围功能出镜
- [ ] 评委提问预演 4 问全部有演示锚点

---

## 五、一句话总结

> 从"展示我们做了什么"（功能堆砌）转向"展示我们证明了什么"（证据链 + 诚实量化 + 成长对比）——用 10 分钟让评委看到：这个系统认识你，并且能证明它认识你。
