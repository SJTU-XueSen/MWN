🔒 数据存储说明

💾

SQLite 本地数据库

结构化数据（记录、事件、人格、目标等）存储在本地加密存储中。MVP 阶段使用本地 SQLite，后续可迁移至加密云数据库。

🧬

ChromaDB 向量数据库

语义记忆以向量形式存储在本地 ChromaDB 中，用于 AI 检索和理解。仅存储语义特征，不存储原始文本的全部内容。

🤖

AI 分析过程

当使用 DeepSeek 或智谱 API 进行分析时，文本内容会发送至对应服务商。我们不存储 API 调用记录，仅保存分析结果。
