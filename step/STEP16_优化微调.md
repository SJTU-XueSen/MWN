# STEP 16: 优化微调

## 概述

在15步核心功能开发完成后，进行了多轮深度产品迭代和体验优化。

## 改动清单

### 一、AI 分析系统

| 改动 | 说明 |
|------|------|
| LLM 接入 | DeepSeek + 智谱 GLM 双引擎，规则回退 |
| 联网搜索 | Wikipedia + DuckDuckGo 免费搜索链，专业术语自动查背景 |
| 诚实反思 | Journal/Event Prompt 加入 `honest_reflection`——不只鼓励，也指出怠惰和拖延 |
| 引擎标识 | 页面标注分析来源（DeepSeek/规则引擎），用户可知 |

### 二、人生参考

| 改动 | 说明 |
|------|------|
| 真实经历搜索 | 6 个分类（考研/求职/创业/转行/大学生活/失败教训），搜索知乎等平台个人经历 |
| 精准推送 | 根据用户专业和兴趣个性化搜索词 |
| 源站链接 | 每篇文章可点击跳转原文，标注平台来源 |
| 点击追踪 | 参考浏览偏好作为人格权重信号，影响画像和模拟 |

### 三、用户行为追踪

| 改动 | 说明 |
|------|------|
| 页面访问追踪 | PageVisit 表记录每次访问，upsert 计数 |
| 参考点击追踪 | 分类查看和文章点击单独追踪 |
| 仪表盘洞察 | "你最常访问：XX" + "你对XX类真实经历特别关注" |
| 人格权重 | 参考点击数据注入 Persona 画像生成 |

### 四、日期输入统一

所有日期输入从三下拉框改为原生 `<input type="date">`，与成长报告页保持一致。

### 五、数据库可靠性

| 问题 | 修复 |
|------|------|
| 重启丢数据 | 移除重启脚本中的 `rm app.db`，数据持久保留 |
| 用户数据串号 | `init_db()` 启动时自动清理 ChromaDB 孤立向量 |
| 所有查询加 user_id | 聊天消息、事件记忆查询增加直接 user_id 过滤 |
| 新字段热迁移 | `ALTER TABLE` 手动补列，不丢数据 |

### 六、CLAUDE.md 强制指令

创建项目级 `CLAUDE.md`，六大章节强制约束所有 AI 输出必须有数据来源。

### 七、人生模拟器迭代

| 版本 | 改动 |
|------|------|
| v1 | 三路径卡片，人格化标签 |
| v2 | 量化指标（成长距离/人格倾向/契合度），数据驱动 |
| v3 | 回档 GitHub 原版，恢复哲学化描述 |
| v4 | 中立标签 + 条件语气里程碑 + 人格倾向 ↑↓ 符号 |
| v5 | 关键记忆溯源 + 价值取向 + 取舍（得到/放弃） |
| v6 | 顶栏三层量化对比，匹配度可展开证据 |
| v7 | 人格倾向 vs 成长能力分离，规则路径全数据驱动 |
| v8 | 一键设为目标 + 保存未来版本 |

### 八、人生拟真体验（新增模块）

| 组件 | 说明 |
|------|------|
| SimulationSession | 体验会话：人格权重快照 + 随机种子 + 事件日志 |
| 叙事引擎 | LLM 场景生成 + 规则回退，每选择有收益/代价 |
| 状态面板 | 人格倾向（稳定）+ 成长能力（可变）分离显示 |
| 开放式选择 | 三个预设 + 自定义输入 |
| 记忆触发 | ChromaDB 真实记忆注入叙事 |
| 重大事件持续影响 | 辞职/创业等选择产生持续生活状态变化 |
| 代价机制 | 每个选择都有升有降 |

### 九、未来对话升级

| 改动 | 说明 |
|------|------|
| 跨时空对话感 | 时间坐标 + 共享记忆 + 身份标签 |
| 智谱 GLM 支持 | 优先流式，回退 DeepSeek |
| 流式输出 | SSE 逐字吐回，无全屏 loading |
| 真人感 Prompt | 口语化、可表达脆弱、不总是给答案 |

### 十、目标系统升级

| 改动 | 说明 |
|------|------|
| AI 差距分析 | 基于人格+记录数+事件生成差距和行动建议 |
| 完整表单 | 类型/周期/重要度滑块/目标年份 |
| 一键设为目标 | 模拟路径转化为目标+子目标 |
| 版本历史查看 | 数字人格历史版本可点击查看 |

### 十一、仪表盘增强

| 改动 | 说明 |
|------|------|
| 成长洞察 | 连续记录天数 / 本周vs上周 / AI 洞察 |
| 6 列统计卡片 | 新增成长报告计数 |
| 目标快捷操作 | 完成/删除按钮 |

### 十二、加载优化

| 场景 | 方式 |
|------|------|
| AI 操作（写记录/生成报告/模拟） | 全屏 loading 遮罩 + 按钮禁用防重复 |
| 未来对话 | 流式 SSE 逐字输出，无遮罩 |
| 登录/注册/资料 | `data-no-loading` 跳过 |

## 数据流最终架构

```
用户输入 → SQLite（11表）+ ChromaDB（单Collection, user_id隔离）
              ↓
       LLM 分析（DeepSeek/智谱）+ 规则回退 + 联网搜索
              ↓
       LifeMemory → PersonaProfile → InterestTrack
              ↓
       Simulation → FutureSelf → SimulationSession
              ↓                    ↓
       人生地图（宏观）        人生体验（微观）
       三路径卡片              叙事模拟器
       ↓                    ↓
       未来对话（流式）       设为目标（行动）
              ↓
       成长反馈（仪表盘洞察 + 连续记录 + 参考点击追踪）
```
