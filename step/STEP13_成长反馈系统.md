# STEP 13: 成长反馈系统

## 完成内容

### 仪表盘内嵌的持续成长反馈

不同于 Step 9 的成长报告（手动触发、长周期摘要），成长反馈是嵌入首页的**自动持续洞察**——用户每次登录都能看到。

### 新增指标

| 指标 | 计算方式 | 展示 |
|------|---------|------|
| **连续记录天数** | 从今天/昨天往前数连续有记录的日期 | 数字 + 颜色（≥7天绿色🔥，≥3天琥珀色） |
| **本周 vs 上周** | 近7天 vs 前7天记录数对比 | 条数 + ↑↓箭头 + 差值 |
| **AI 成长洞察** | 综合 streak/week_change/goal_progress/总数据量 | 一句话反馈（🧠卡片） |
| **已完成目标数** | LifeGoal status="achieved" 的数量 | 统计卡片 |

### 改动文件

| 文件 | 改动 |
|------|------|
| `services/dashboard_service.py` | 新增 streak 算法、周度对比、目标完成统计、`_generate_insight()` 洞察生成器 |
| `templates/index.html` | 统计卡片下方新增"成长洞察"行（3 卡片：AI洞察/连续记录/本周对比） |

### AI 洞察规则

```
连续 ≥7 天 → "你已经连续N天记录人生，这是很可贵的自我觉察习惯"
连续 3-6 天 → "连续N天记录了，保持这个节奏"
连续 0 天 → "今天还没有记录，花2分钟写下今天的感受吧"

本周 > 上周 → "本周记录比上周多了N条，状态在回升"
本周 < 上周 → "本周记录比上周少了N条，是不是最近比较忙？"

已完成 ≥1 目标 → "已经完成了N个目标，每一步都算数"
无目标 + 记录多 → "还没有设定目标？设定一两个方向会让AI更准确地理解你"

总数据 ≥20 → "数据积累已经比较丰富了，AI对你的理解越来越准确"
总数据 ≥5 → "数据在慢慢积累，再多记录一些"
```

### 设计决策

- **嵌入仪表盘而非独立页面**：成长反馈的价值在于"每次看到"，不需要用户主动去找
- **规则驱动而非 LLM**：洞察基于简单规则生成，零延迟、零 API 消耗、随时可用
- **正向 + 诚实**：既表扬连续记录，也会提醒"这周比上周少了"
- **可扩展**：`_generate_insight()` 函数独立，后续可接入 LLM 生成更个性化的洞察
