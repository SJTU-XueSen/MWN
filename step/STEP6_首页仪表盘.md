# STEP 6: 首页仪表盘 + 全局布局 — 审核

## 完成内容

### 全局布局 (`templates/base.html`)

| 组件 | 说明 |
|------|------|
| 侧边栏 | 暗色半透明，56px 宽，"探索"和"实验室"两组导航 |

### 首页仪表盘 (`/`)

数据驱动的 Dashboard，调用 `services/dashboard_service.py` 聚合以下数据：

| 区块 | 数据源 | 展示内容 |
|------|--------|----------|
| 欢迎语 | User + PersonaProfile | "根据 N 条记录，你正在成为 **探索型创造者**" |
| 5个统计卡片 | LifeEvent/DailyRecord/LifeGoal/Simulation/DailyRecord | 人生事件/日常记录/活跃目标/人生模拟/本周记录 |
| 3个快速操作 | — | 记录事件/查看人格/人生模拟 |
| 最近事件列表 | LifeEvent (latest 5) | 图标+标题+类型标签+情绪+日期，11种事件类型各有对应图标和颜色 |
| 数字人格预览 | PersonaProfile | 人格类型+置信度+版本+四维能力条 |
| 兴趣分布 | InterestTrack (去重最新) | 各领域分数条 |
| 活跃目标 | LifeGoal (top 3) | 类型图标+描述+重要度+目标年份 |

### 空状态处理

- 无人格画像 → 提示"多记录经历后AI将生成"
- 无事件 → 引导"记录第一段经历"
- 无目标 → 引导"设定你的方向"
