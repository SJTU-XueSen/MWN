# STEP 10: 阶段二 — 数字人格画像

## 完成内容

### 数字人格系统落地

这是"AI人生镜像"的核心模块——从用户积累的全部人生数据中提炼出一个五维数字人格。

### 数据流

```
用户点击"生成画像"
    ↓
POST /persona/generate
    ↓
_collect_user_data() 汇总全部人生数据：
  ├── 所有 DailyRecord（AI 分析提取的兴趣/行为/情绪）
  ├── 所有 LifeEvent（事件类型统计）
  ├── 所有 LifeMemory（重要性排序，取 Top 30）
  ├── 所有 InterestTrack（兴趣演进去重）
  └── 活跃 LifeGoal
    ↓
LLM 分析（优先）或 规则聚合（回退）
    ↓
PersonaProfile 存入 SQLite
  ├── 旧版本标记 is_current=False
  ├── 新版本 version+1, is_current=True
  └── 保留完整版本历史
    ↓
/persona 可视化展示
```

### 新增文件

| 文件 | 说明 |
|------|------|
| `services/persona_service.py` | 数据聚合 + LLM/规则双引擎画像生成 + 版本管理 |
| `routers/persona.py` | 画像主页 + 生成触发 |
| `templates/persona/detail.html` | 五维画像可视化页面 |

### 路由

| 路由 | 方法 | 功能 |
|------|------|------|
| `/persona` | GET | 画像主页（当前版本 + 版本历史） |
| `/persona/generate` | POST | 触发画像生成/更新 |

### 五维画像展示

| 维度 | 可视化方式 | 数据来源 |
|------|-----------|---------|
| **能力画像** | 水平进度条（技术/创造/社交/自我认知） | 兴趣×记录数交叉计算 |
| **兴趣画像** | 图标+进度条 | InterestTrack 汇总 |
| **价值观画像** | 卡片网格（成就导向/关系重视/求知欲/自主性） | 事件类型推断 |
| **决策风格** | 风格名+特征标签 | 行为模式推断 |
| **行为模式** | 进度条 | 规则引擎行为计数 |

### 版本管理

- 每次生成新画像时，旧版本 `is_current` 自动置为 `False`
- 版本号递增（v1 → v2 → v3...）
- 页面底部展示版本历史时间轴
- 记录 `trigger_event`（触发原因），便于追溯

### 人格类型推断（规则引擎）

| 条件 | 类型 |
|------|------|
| 探索型 + 创造型 模式多 | 探索型创造者 |
| 坚持型模式突出 | 坚韧实践者 |
| 社交型模式突出 | 社交连接者 |
| 反思型模式突出 | 深度思考者 |
| 数据不足 | 成长中的探索者 |

### 设计决策

- **版本化管理**：人格不是一成不变的，每次更新保留历史版本，用户可以看到自己的人格演变
- **置信度透明**：基于数据量计算，记录越多置信度越高（最高 0.85，LLM 模式下可达 0.95）
- **空状态引导**：未生成画像时，引导用户积累数据（建议 5记录+3事件）
- **仪表盘集成**：首页人格预览区现在展示真实画像数据（类型名+能力条）
