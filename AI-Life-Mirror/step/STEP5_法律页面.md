# STEP 5: 法律页面 — 审核

## 完成内容

### 3 个法律页面

| 页面 | 路由 | 核心内容 |
|------|------|----------|
| 用户协议 | `/legal/terms` | 服务说明、用户资格、账户管理、数据所有权、AI生成内容声明、禁止行为、免责条款、协议变更 |
| 隐私政策 | `/legal/privacy` | 数据收集范围、使用目的、存储安全、共享规则、用户权利（访问/修改/删除/导出）、Cookie、未成年人保护 |
| 免责声明 | `/legal/disclaimer` | AI分析局限性、非专业服务声明、人格模拟局限、数据准确性、技术免责、用户责任、责任限制 |

### 关键条款亮点

- **数据所有权**：明确"您的数据属于您自己"
- **AI 内容声明**：强调数字人格是统计推断，模拟路径非预测，用户应保持独立思考
- **用户权利**：访问权、修改权、删除权、导出权、撤销同意权
- **非专业服务**：明确本平台不是心理咨询、职业规划、教育咨询、法律服务

### 新增/修改文件

| 文件 | 说明 |
|------|------|
| `routers/legal.py` | 3 条路由，不需登录即可访问 |
| `templates/legal/terms.html` | 用户协议，9 个章节 |

| `templates/legal/disclaimer.html` | 免责声明，8 个章节 |
| `templates/guest_base.html` | 页脚加入法律页面链接 |
| `main.py` | 注册 legal_router |

### 设计决策

- 法律页面使用 guest 布局（不需登录），已登录用户显示"返回首页"链接
- 所有页面底部 footer 均包含用户协议、隐私政策、免责声明入口
- 注册/登录页面底部有"注册即表示同意用户协议和隐私政策"提示
